## 📖 เกี่ยวกับโปรเจกต์นี้

โปรเจกต์นี้จัดทำขึ้นเพื่อแปลและเผยแพร่เนื้อหาฉบับภาษาไทยของวิทยานิพนธ์ *Softwar* ซึ่งนำเสนอ **ทฤษฎีการแผ่ขยายอำนาจ (Power Projection Theory)** และมุมมองใหม่ที่ว่า **บิตคอยน์ไม่ได้เป็นเพียงเทคโนโลยีทางการเงิน แต่เป็น "โปรโตคอลการแผ่ขยายอำนาจทางกายภาพในไซเบอร์สเปซ" (ซอฟต์วอร์)** ที่มีนัยสำคัญต่อความมั่นคงเชิงยุทธศาสตร์แห่งชาติในศตวรรษที่ 21

เป้าหมายคือทลายกำแพงภาษา เพื่อให้ผู้สนใจด้านบิตคอยน์ เทคโนโลยี และความมั่นคงในประเทศไทย เข้าถึงและเข้าใจทฤษฎีระดับโลกนี้ได้อย่างลึกซึ้ง

## ✨ ฟีเจอร์การอ่าน

- 🔖 **อ่านต่อจากจุดเดิม (Resume Reading)** — เว็บจำตำแหน่งที่อ่านล่าสุดอัตโนมัติ (เก็บใน `localStorage` ของเบราว์เซอร์)
  - เปิดครั้งต่อไป **เด้งกลับไปจุดเดิมให้เอง** (ยกเว้นเข้ามาทางลิงก์ `#...`)
  - มีปุ่ม **"↩ อ่านต่อ"** ข้างตัวเลือกขนาดตัวอักษร กดเพื่อกลับจุดเดิมได้ตลอด (ชี้เมาส์ค้างจะเห็นหัวข้อล่าสุด)
  - จำเป็น "หัวข้อ + ระยะ offset" ไม่ใช่ค่า scroll ดิบ จึงแม่นแม้เนื้อหาโหลดแบบ lazy · จำแยกกันระหว่างเวอร์ชันออนไลน์กับไฟล์ออฟไลน์ (คนละ origin)
- 🌗 **สลับธีมสว่าง/มืด** และ 🔤 **ปรับขนาดตัวอักษร 7 ระดับ** (จำค่าที่เลือกไว้)
- 📊 **แถบความคืบหน้าการอ่าน** ด้านบน + เมนูสารบัญไฮไลต์หัวข้อที่กำลังอ่านอัตโนมัติ (scroll-spy)
- ⚡ **โหลดเร็ว** ด้วย lazy-load แต่เลื่อนอ่านต่อเนื่องลื่นเหมือนไฟล์เดียว · ตัดคำไทยอัตโนมัติให้ตัดบรรทัดสวยงาม

## 🛠️ โครงสร้างทางเทคนิค

เว็บออกแบบให้ **โหลดเร็วบนอินเทอร์เน็ตที่ช้า** ด้วยการแยกเนื้อหาออกจาก `index.html` (จาก 3.1 MB เหลือ ~57 KB) แล้วโหลดเนื้อหาแต่ละบทแบบ lazy-load เมื่อผู้อ่านเลื่อนถึง — แต่การอ่านยังไหลลื่นต่อเนื่องเหมือนไฟล์เดียว

```
index.html              โครงเครื่อง (CSS + เมนู + hero + JS loader) ~57 KB — สำหรับโฮสต์
Softwar_offline.html    ไฟล์เดียวรวมทั้งเล่ม ~4.3 MB — ดับเบิลคลิกอ่านออฟไลน์
index-full.html         สำเนาไฟล์เดียวเดิม (สำรองไว้ rollback)
content/                เนื้อหาแยกไฟล์ (frontmatter, ch1–ch3, ch4-1…ch6-4, bibliography)
images/                 ภาพประกอบ Figure 1–97
STRUCTURE.md            คู่มือสถาปัตยกรรมและวิธีแก้/เพิ่มเนื้อหาโดยละเอียด
```

รายละเอียดสถาปัตยกรรม การตั้งชื่อไฟล์ และวิธีแก้เนื้อหา ดูใน **[`STRUCTURE.md`](STRUCTURE.md)**

### ▶️ รันบนเครื่อง (ต้องผ่านเว็บเซิร์ฟเวอร์ — เปิดไฟล์ index.html ตรง ๆ จะโหลดเนื้อหาไม่ได้)

```bash
cd "Softwar TH - Webpage"
```
